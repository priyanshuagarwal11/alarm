# ⏰ Digital Clock & Alarm

A simple and interactive **Digital Clock with Alarm Web Application** built using **HTML, CSS, and JavaScript**.  
The app displays real-time time and allows users to set an alarm with instant notification.

---

## 🛠️ Tech Stack
- **HTML** – Structure of the clock  
- **CSS** – Styling and layout  
- **JavaScript** – Time logic, alarm handling  

---

## ✨ Features
✅ Real-time digital clock  
✅ Set alarm using time input  
✅ Alarm notification alert  
✅ Simple and clean UI  
✅ Fully responsive design

## ⚙️ How It Works
1. JavaScript `Date` object fetches current time  
2. `setInterval()` updates the clock every second  
3. User sets alarm time using input  
4. Alarm triggers when current time matches alarm time
